Resistor

Função: Limita ou controla a passagem de corrente elétrica em um circuito.

Uso comum: Proteger componentes sensíveis (como LEDs) e ajustar tensões.

Exemplo prático: Em um circuito com LED, o resistor evita que o LED queime por excesso de corrente.

Simbologia

diodo LED

Simbologia

Função: Emite luz quando a corrente elétrica passa por ele em um único sentido.

Características: Possui polaridade (lado positivo — ânodo / lado negativo — catodo).

Uso comum: Indicadores luminosos em painéis, eletrônicos e iluminação.

Exemplo prático: Luz de "ligado/desligado" em aparelhos eletrônicos.

Transistor

Função: Atua como chave eletrônica (liga/desliga) ou amplificador de sinal.

Tipos principais: NPN e PNP (bipolares), MOSFET (de efeito de campo).

Uso comum: Em circuitos de amplificação de som, fontes de energia e microcontroladores.

Exemplo prático: Controle da velocidade de motores ou volume de áudio.

Simbologia

Circuito Integrado

Simbologia

Função: Reúne vários componentes eletrônicos (transistores, resistores, capacitores) em um único chip.

Vantagem: Diminui o tamanho dos circuitos e aumenta a eficiência.

Uso comum: Em computadores, celulares, fontes chaveadas e microcontroladores (como o Arduino).

Exemplo prático: O CI 555 é usado como temporizador; o CI 7400 em circuitos lógicos.

Arduino

O que é?

O Arduino é uma plataforma de prototipagem eletrônica de código aberto (open source), formada por uma placa com microcontrolador e um software (Arduino IDE) usado para programá-la.

Ele permite criar e testar projetos eletrônicos de forma simples, mesmo para iniciantes.

Para que serve/
aplicações

O Arduino serve para controlar dispositivos eletrônicos automaticamente, lendo informações do ambiente (sensores) e reagindo a elas (atuadores).

Algumas aplicações comuns:

  • 🌡️ Estações meteorológicas (temperatura, umidade, chuva)
  • 🤖 Robôs e carrinhos autônomos
  • 💡 Automação residencial (controle de luzes, portões, irrigação)
  • 🎓 Projetos educacionais de eletrônica e programação
  • 🚨 Alarmes e sistemas de segurança
  • 🚗 Protótipos automotivos (controle de motores, sensores de distância)

Vantagens

  • 💻 Fácil de programar com linguagem simples baseada em C/C++
  • 📍 Grande variedade de sensores e módulos compatíveis
  • 👥 Comunidade ativa e tutoriais disponíveis
  • 💰 Baixo custo e acessível para estudantes
  • 🔧 Open source, ou seja, livre para modificar e compartilhar

Desvantagens

  • ⚡ Baixo poder de processamento (limitado para projetos muito complexos)
  • 💾 Pouca memória comparado a microcontroladores avançados
  • 🐢 Velocidade menor que placas como Raspberry Pi
  • 📱 Dependência de hardware externo para funções específicas (Wi-Fi, Bluetooth, etc.)

Como o Arduino funciona?

O Arduino funciona como o "cérebro" de um projeto eletrônico.

Ele recebe informações do ambiente, processa esses dados e controla dispositivos de acordo com o que foi programado.

1. Entradas (Input)

São os sensores e dispositivos que enviam informações para o Arduino.

Exemplos:

  • Sensor de temperatura 🌡️
  • Sensor de luz (LDR) 💡
  • Botão ⚪

Esses componentes mandam sinais elétricos para os pinos de entrada da placa.

2. Processamento

O microcontrolador (geralmente um ATmega328 no Arduino Uno) interpreta o programa que você gravou nele usando a IDE Arduino.

Ele decide o que fazer com os dados recebidos — por exemplo: "Se o sensor de luz detectar escuridão, acenda o LED."

3. Saídas (Output)

Depois de processar as informações, o Arduino envia comandos para os dispositivos de saída.

Exemplos:

  • Acender um LED 💡
  • Ligar um motor 🔌
  • Tocar um som 🔊
  • Enviar dados para um display 🖥️

Essas ações acontecem nos pinos de saída digital ou analógica da placa.

4. Programação

O comportamento do Arduino é definido por um programa (sketch) escrito na Arduino IDE, em linguagem baseada em C/C++.

Depois que o código é compilado e enviado para a placa via cabo USB, ele fica gravado no microcontrolador e é executado automaticamente.

5. Alimentação

O Arduino pode ser ligado por:

  • Cabo USB 🔌
  • Bateria 🔋
  • Fonte externa ⚡

Ele converte a energia para alimentar tanto o próprio circuito quanto os sensores e atuadores conectados.

O que é eletrônica embarcada?

A eletrônica embarcada é o conjunto de componentes eletrônicos e sistemas de controle que são instalados dentro de máquinas, veículos, aparelhos ou equipamentos, para realizar funções automáticas específicas.

Em outras palavras, é a eletrônica "escondida" dentro dos dispositivos que usamos no dia a dia, fazendo tudo funcionar sem precisarmos perceber.

Como funciona

Um sistema embarcado combina:

  1. Hardware — sensores, atuadores, microcontroladores (como o Arduino).
  2. Software — programas que controlam o funcionamento do sistema.

Esses dois elementos trabalham juntos para monitorar, processar e controlar alguma função específica.

Exemplos de Eletrônica Embarcada

  • Carros: controle de injeção eletrônica, freios ABS, airbags, sensores de estacionamento.
  • Celulares: controle de tela, câmera, bateria e sensores de movimento.
  • Eletrodomésticos inteligentes: micro-ondas, máquinas de lavar, geladeiras automatizadas.
  • Aviões e drones: sistemas de navegação e estabilidade.
  • Máquinas industriais: controle de motores, temperatura e processos automáticos.

Vantagens

  • Automação e precisão nos sistemas
  • Economia de energia
  • Maior segurança e confiabilidade
  • Facilidade de manutenção e monitoramento

Desvantagens

  • Difícil de modificar (projetos muito específicos)
  • Custo maior em equipamentos simples
  • Necessidade de técnicos especializados

Linguagem de Programação usada no Arduino

O Arduino é programado em uma linguagem baseada em C e C++, dentro do software Arduino IDE.

Simples e fácil de entender.

Usa funções próprias, como setup() (configuração) e loop() (repetição).

void setup() {
pinMode(13, OUTPUT); // Define o pino 13 como saída
}

void loop() {
digitalWrite(13, HIGH); // Liga o LED
delay(1000);            // Espera 1 segundo
digitalWrite(13, LOW);  // Desliga o LED
delay(1000);            // Espera 1 segundo
}
