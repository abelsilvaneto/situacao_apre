O que são Redes de Computadores?

Redes de Computadores são estruturas que permitem a comunicação e o compartilhamento de recursos entre dois ou mais dispositivos — como computadores, celulares, impressoras, servidores e roteadores — conectados por meios físicos (cabos) ou sem fio (Wi-Fi). Elas existem para que os dispositivos possam trocar informações, acessar a internet, compartilhar arquivos e trabalhar juntos de forma rápida e segura.

O que uma rede possibilita?

  • Compartilhar internet entre vários dispositivos
  • Compartilhar arquivos e impressoras
  • Permitir comunicação entre pessoas (e-mail, mensagens, voz)
  • Acessar sistemas corporativos
  • Realizar backup e armazenamento em servidores

Tipos de Redes

  • LAN (Local Area Network) Rede local, usada em casas, escolas e empresas.
  • WAN (Wide Area Network) Rede de longa distância, que conecta cidades, estados ou países.
  • MAN (Metropolitan Area Network) Rede usada para interligar áreas urbanas inteiras.

Elementos que formam uma rede

  • Roteador: distribui conexão e encaminha pacotes.
  • Switch: conecta vários dispositivos dentro da rede local.
  • Modem: liga a rede à internet do provedor.
  • Cabos (Ethernet) ou Wi-Fi para realizar a comunicação.

O que é a internet? O que compõe?


A internet é uma imensa rede global que conecta milhões de dispositivos, permitindo a troca de informações de forma rápida e segura. Ela é formada por uma grande infraestrutura física composta por cabos, servidores, antenas e equipamentos que transportam os dados. Além disso, conta com provedores que oferecem acesso aos usuários e com protocolos de comunicação que padronizam a forma como os dados são enviados e recebidos. Servidores espalhados pelo mundo hospedam sites, aplicativos e serviços, tornando possível acessar redes sociais, vídeos, e-mails e muito mais. Por fim, a participação dos usuários e de seus dispositivos completa todo esse ecossistema, tornando a internet uma ferramenta essencial para a comunicação e o funcionamento da sociedade moderna.


O que é uma Rede mínima?


Uma rede mínima é a forma mais simples possível de uma rede de computadores, composta apenas pelos elementos essenciais para que dois dispositivos consigam se comunicar. Para que uma rede exista, é necessário ter pelo menos dois equipamentos conectados por algum tipo de meio de comunicação, como um cabo de rede, Wi-Fi ou até Bluetooth. Mesmo com essa estrutura reduzida, já é possível realizar troca de informações, enviar arquivos e estabelecer comunicação entre os aparelhos. Assim, a rede mínima representa o ponto de partida para qualquer rede maior e mais complexa, servindo como base para entender como os dispositivos se conectam e interagem dentro de um ambiente de rede.


O que é web?

A web, também conhecida como World Wide Web (WWW), é um conjunto de páginas, sites e conteúdos que podem ser acessados pela internet por meio de navegadores, como Chrome, Firefox ou Edge. Enquanto a internet é a rede mundial de computadores, a web é um dos serviços que funciona dentro dela, responsável pela navegação em sites, visualização de texto, imagens, vídeos e interação com plataformas online.

O que compõe a Web?

  • Páginas Web São documentos escritos principalmente em HTML, que podem conter texto, imagens, vídeos e links.
  • Navegadores (Browsers) Programas usados para acessar a web. Exemplos: Chrome, Firefox, Safari, Edge.
  • Servidores Web Computadores que armazenam sites e enviam as páginas para os usuários quando solicitadas.
  • URLs Endereços que usamos para acessar páginas. Exemplo: https://www.exemplo.com .
  • Protocolos Regras que permitem a comunicação entre navegador e servidor: HTTP HTTPS (versão segura)

O que é o mapa de fibra óptica


O mapa de fibra óptica (frequentemente chamado de submarine cable map quando mostra cabos submarinos) é uma representação gráfica das rotas físicas que conectam redes entre países e continentes — principalmente cabos de fibra óptica subaquáticos e também enlaces terrestres e estações de aterragem (landing stations). Esses mapas mostram onde os cabos passam pelo oceano, onde tocam a costa e quais sistemas ou consórcios são responsáveis por cada rota.


Vantagens

  • Fácil de programar com linguagem simples baseada em C/C++
  • Grande variedade de sensores e módulos compatíveis
  • Comunidade ativa e tutoriais disponíveis
  • Baixo custo e acessível para estudantes
  • Open source, ou seja, livre para modificar e compartilhar

Desvantagens

  • Baixo poder de processamento (limitado para projetos muito complexos)
  • Pouca memória comparado a microcontroladores avançados
  • Velocidade menor que placas como Raspberry Pi
  • Dependência de hardware externo para funções específicas (Wi-Fi, Bluetooth, etc.)

Como o Arduino funciona?

O Arduino funciona como o "cérebro" de um projeto eletrônico.

Ele recebe informações do ambiente, processa esses dados e controla dispositivos de acordo com o que foi programado.



1. Entradas (Input)

São os sensores e dispositivos que enviam informações para o Arduino.

Exemplos:

  • Sensor de temperatura
  • Sensor de luz (LDR)
  • Botão

Esses componentes mandam sinais elétricos para os pinos de entrada da placa.

2. Processamento

O microcontrolador (geralmente um ATmega328 no Arduino Uno) interpreta o programa que você gravou nele usando a IDE Arduino.

Ele decide o que fazer com os dados recebidos — por exemplo: "Se o sensor de luz detectar escuridão, acenda o LED."

3. Saídas (Output)

Depois de processar as informações, o Arduino envia comandos para os dispositivos de saída.

Exemplos:

  • Acender um LED
  • Ligar um motor
  • Tocar um som
  • Enviar dados para um display

Essas ações acontecem nos pinos de saída digital ou analógica da placa.

4. Programação

O comportamento do Arduino é definido por um programa (sketch) escrito na Arduino IDE, em linguagem baseada em C/C++.

Depois que o código é compilado e enviado para a placa via cabo USB, ele fica gravado no microcontrolador e é executado automaticamente.

5. Alimentação

O Arduino pode ser ligado por:

  • Cabo USB
  • Bateria
  • Fonte externa

Ele converte a energia para alimentar tanto o próprio circuito quanto os sensores e atuadores conectados.



O que é eletrônica embarcada?



A eletrônica embarcada é o conjunto de componentes eletrônicos e sistemas de controle que são instalados dentro de máquinas, veículos, aparelhos ou equipamentos, para realizar funções automáticas específicas.

Em outras palavras, é a eletrônica "escondida" dentro dos dispositivos que usamos no dia a dia, fazendo tudo funcionar sem precisarmos perceber.

Como funciona

Um sistema embarcado combina:

  • Hardware — sensores, atuadores, microcontroladores (como o Arduino).
  • Software — programas que controlam o funcionamento do sistema.

Esses dois elementos trabalham juntos para monitorar, processar e controlar alguma função específica.

Exemplos de Eletrônica Embarcada

  • Carros: controle de injeção eletrônica, freios ABS, airbags, sensores de estacionamento.
  • Celulares: controle de tela, câmera, bateria e sensores de movimento.
  • Eletrodomésticos inteligentes: micro-ondas, máquinas de lavar, geladeiras automatizadas.
  • Aviões e drones: sistemas de navegação e estabilidade.
  • Máquinas industriais: controle de motores, temperatura e processos automáticos.

Vantagens

  • Automação e precisão nos sistemas
  • Economia de energia
  • Maior segurança e confiabilidade
  • Facilidade de manutenção e monitoramento

Desvantagens

  • Difícil de modificar (projetos muito específicos)
  • Custo maior em equipamentos simples
  • Necessidade de técnicos especializados


Linguagem de Programação usada no Arduino



O Arduino é programado em uma linguagem baseada em C e C++, dentro do software Arduino IDE.

Simples e fácil de entender.

Usa funções próprias, como setup() (configuração) e loop() (repetição).

void setup() {
pinMode(13, OUTPUT); // Define o pino 13 como saída
}

void loop() {
digitalWrite(13, HIGH); // Liga o LED
delay(1000);            // Espera 1 segundo
digitalWrite(13, LOW);  // Desliga o LED
delay(1000);            // Espera 1 segundo
}

O que são entradas e saídas digitais em circuitos integrados como o Arduíno



Entrada Digital (resumo curto) Uma entrada digital é um pino do Arduino usado para ler sinais do ambiente que só podem ter dois estados: ligado ou desligado. Ela identifica se um componente, como um botão ou sensor, está enviando um sinal HIGH (1) ou LOW (0), permitindo que o Arduino detecte ações ou eventos externos.


Saída Digital (resumo curto) Uma saída digital é um pino do Arduino usado para enviar sinais para controlar dispositivos. Ela coloca o pino em HIGH (1) para ligar algo, como um LED ou relé, e em LOW (0) para desligar, permitindo que o Arduino ative ou desative equipamentos eletrônicos.

O que são entradas e saídas analógicas em circuitos integrados como o Arduíno



Entradas Analógicas Entradas analógicas são pinos usados para ler valores que variam continuamente, não apenas ligado/desligado. Em vez de ler apenas HIGH ou LOW, o Arduino consegue medir diferentes níveis de tensão, normalmente entre 0V e 5V, convertendo essa variação em um número entre 0 e 1023 (usando o conversor A/D – ADC).

Exemplos de sensores que usam entrada analógica:

  • Sensor de luminosidade (LDR)
  • Potenciômetro
  • Sensor de temperatura (ex.: LM35)
  • Sensores de gás
  • Sensor de umidade do solo

Saídas Analógicas O Arduino não possui saídas analógicas reais, mas sim saídas PWM, que simulam um sinal analógico variando a largura dos pulsos. Com PWM, o Arduino envia valores entre 0 e 255, criando efeitos intermediários entre desligado e ligado.

Exemplos de uso de saída “analógica” (PWM):

  • Ajustar brilho de LEDs
  • Controlar velocidade de motores
  • Regular intensidade de ventiladores
  • Controlar servomotores (indiretamente)

O que é um diodo?

Um diodo é um componente eletrônico que permite a passagem de corrente elétrica em apenas um sentido. Ele funciona como uma “válvula” elétrica: deixa a corrente passar em um lado (sentido direto) e bloqueia no outro (sentido reverso). É muito usado em retificadores, fontes de energia e proteção de circuitos.



O que é um diodo LED?

O LED (Light Emitting Diode) é um tipo especial de diodo que, além de conduzir corrente em apenas um sentido, emite luz quando a corrente passa por ele. Pode ter diferentes cores (vermelho, azul, verde, branco) e é usado em indicadores, iluminação, painéis e dispositivos eletrônicos em geral.


O que é um display de 7 segmentos?

Um display de 7 segmentos é um componente formado por 7 LEDs organizados em forma de “8”, permitindo exibir números de 0 a 9 e algumas letras simples. Cada “segmento” acende separadamente, e a combinação deles forma o número desejado. É muito usado em relógios digitais, calculadoras, painéis eletrônicos e medidores.


Apresenando um programa para leitura de dados de um sensor analógico, acionando saídas digitais. 

const express = require('express')
const app = express()
const { SerialPort, ReadlineParser } = require('serialport')
const readline = require('readline')

const cors = require('cors')

const PORT = 3000   // PORT do protocolo TCP
const hostname = 'localhost'    // nome do Computador e seu IP = 127.0.0.1 (IP de teste)

const BAUD_RATE = 9600
const SERIAL_PORT = "COM9"

// ------ config de Middleware ----------
app.use(express.urlencoded({extended: true}))
app.use(express.json())
app.use(cors())

// -------- INICIALIZAÇÃO ARDUINO -------------
const arduino = new SerialPort({
    path: SERIAL_PORT,
    baudRate: BAUD_RATE,
})

const parserDados = arduino.pipe(new ReadlineParser({delimiter: "\r\n"}))

arduino.on("open", ()=>{
    console.log(`Conectado ao Arduino em ${SERIAL_PORT}`)
})

arduino.on("error", (err)=>{
    console.error('Erro na comunicação serial', err)
})

// --- parser das linhas: garantir a recepção completa dos dados
parserDados.on("dados", (dad)=>{
    const linha = dad.toString().trim()

    if(linha > 0){
        console.log('Arduino: ',linha)
    }
})

// -------- leitura do teclado para testes / troca de dados manuais -----------

const teclado = readline.createInterface({
    input: process.stdin,
    output: process.stdout,
})

teclado.on("line", (input)=>{
    const comando2 = input.trim()

    if(comando2 === 's' || comando2 === 'd'){
        arduino.write(comando2, (err)=>{
            if(err){
                console.error("Erro ao enviar ocomando pelo teclado: ", err)
            }else{
                console.log(`Comando: ${comando2} enviado ao arduino via teclado`)
            }
        })
    }else{
        console.log("Digite 's' (ligar) ou 'd' (desligar) ")
    }
})

// ------- programando as rotas http => endpoints -----

app.get('/ligar', (req,res)=>{
    arduino.write("s", (err)=>{
        if(err){
            console.error("Erro ao escrever no arduino: ", err)
            return res.status(500).json({ led: "erro", detalhe: "falha ao enviar o comando"})
        }
    })
    res.status(200).json({ led: "ligado"})
})

app.get('/desligar', (req,res)=>{
    arduino.write("d", (err)=>{
        if(err){
            console.error("Erro ao escrever no arduino: ", err)
            return res.status(500).json({ led: "erro", detalhe: "falha ao enviar o comando"})
        }
    })
    res.status(200).json({ led: "desligado"})
})




app.listen(PORT, hostname, ()=>{
    console.log(`Servidor rodando em ${hostname}:${PORT}`)
    console.log("Digite 's' para ligar e 'd' para desligar")
    console.log('-------------------------------------------')
})
