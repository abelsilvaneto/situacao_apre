O que são fluxogramas?
Qual a sua simbologia básica?

fluxogramas

Fluxogramas são ferramentas gráficas usadas para representar visualmente etapas de um processo, mostrando de forma clara a sequência de atividades, decisões, entradas e saídas. Eles são muito usados em:

  • Análise e melhoria de processos
  • Documentação de sistemas
  • Programação e lógica computacional
  • Treinamentos e padronização de procedimentos

O que são algoritmos? Onde são usados?

algoritmos

Os principais bancos de dados são aqueles mais usados no mercado por sua confiabilidade, desempenho e facilidade de integração com diversos sistemas. Eles podem ser relacionais (SQL) ou não relacionais (NoSQL).

Bancos de Dados Relacionais (SQL)

Esses armazenam dados em tabelas com linhas e colunas, e utilizam a linguagem SQL (Structured Query Language) para consultar e manipular informações.

  • MySQL Um dos mais populares do mundo, gratuito e de código aberto. Muito usado em sites e sistemas web (como WordPress e lojas virtuais).
  • PostgreSQL Open source, conhecido por sua robustez, segurança e suporte a dados complexos.
  • Oracle Database Amplamente usado em grandes empresas; é pago e oferece alta performance e segurança.
  • Microsoft SQL Server Banco de dados da Microsoft, muito utilizado em sistemas corporativos e aplicações Windows.
  • SQLite Leve e simples, ideal para aplicativos móveis e pequenos sistemas, pois não precisa de servidor.

Bancos de Dados Não Relacionais (NoSQL)

Esses bancos armazenam dados de forma flexível, sem seguir o modelo de tabelas, sendo ideais para grandes volumes de dados, redes sociais, e aplicações em tempo real.

  • MongoDB Armazena dados em formato JSON, ótimo para aplicações web modernas.
  • Redis Trabalha com dados na memória, excelente para cache e processamento rápido.
  • Cassandra Criado pelo Facebook, suporta grandes volumes de dados distribuídos.
  • Amazon DynamoDB Serviço da Amazon em nuvem, usado em aplicações que precisam de alta escalabilidade.

O que é um dicionário de dados?
Quais os tipos de dados de um banco de dados?

Um dicionário de dados é um repositório que descreve todas as informações sobre os dados contidos em um banco de dados. Ele não guarda os dados em si, mas sim as informações sobre eles, como nomes, tipos, tamanhos, restrições e relações entre as tabelas. Em outras palavras, o dicionário de dados funciona como um manual de referência do banco, ajudando desenvolvedores e administradores a entenderem como os dados estão organizados e estruturados.

Função do Dicionário de Dados

  • Define o nome e a descrição de cada campo (coluna).
  • Informa o tipo de dado (texto, número, data, etc.).
  • Mostra o tamanho máximo permitido em cada campo.
  • Indica se o campo pode ou não ser nulo.
  • Mostra as relações entre tabelas (chaves primárias e estrangeiras).

Principais Tipos de Dados em um Banco de Dados

  • Numéricos Usados para armazenar números. INT / INTEGER: Números inteiros (ex: 10, -5, 1200) FLOAT / DOUBLE / DECIMAL: Números com casas decimais (ex: 10.5, 3.1416)
  • TextuaisUsados para armazenar letras, palavras ou textos. CHAR: Texto de tamanho fixo (ex: código com 2 letras “BR”) VARCHAR: Texto de tamanho variável (ex: nomes, e-mails) TEXT: Textos longos (ex: descrições, observações)
  • Data e HoraUsados para armazenar informações de tempo. DATE: Apenas a data (ex: 2025-11-13) TIME: Apenas a hora (ex: 14:30:00) DATETIME / TIMESTAMP: Data e hora juntos
  • BooleanosBOOLEAN / BIT: Representa valores verdadeiros ou falsos (ex: 1 = verdadeiro, 0 = falso)
  • BináriosUsados para armazenar arquivos ou dados em formato binário. BLOB (Binary Large Object): Imagens, vídeos, documentos etc.

O que é uma modelagem de banco de dados? E o modelo DER? MER?

A modelagem de banco de dados é o processo de planejar e estruturar como os dados serão organizados dentro de um banco. Ela serve para representar de forma lógica e visual como as informações se relacionam entre si, antes de criar o banco propriamente dito.

Em outras palavras, é como fazer a planta de uma casa antes da construção — a modelagem mostra quais dados existirão, como eles se conectam e como serão armazenados.

O que é Modelagem de Banco de Dados

A modelagem permite: Definir entidades (como clientes, produtos, pedidos). Identificar atributos (como nome, preço, data). Estabelecer relacionamentos entre essas entidades (como “um cliente faz vários pedidos”). Ela é fundamental para evitar erros, redundâncias e perda de dados, garantindo que o banco seja eficiente e bem estruturado.

O que é o Modelo DER (Diagrama Entidade-Relacionamento)

O DER é a representação gráfica da modelagem de banco de dados. Ele mostra como as entidades se conectam, usando símbolos e linhas que indicam os relacionamentos.

Elementos principais do DER:

  • Entidades: São os objetos ou coisas do mundo real que queremos representar (ex: Cliente, Produto, Pedido).
  • Atributos: São as características das entidades (ex: nome, endereço, preço).
  • Relacionamentos: Mostram como as entidades se ligam (ex: Cliente faz Pedido).

O que é o MER (Modelo Entidade-Relacionamento)

O MER (Modelo Entidade-Relacionamento) é o modelo conceitual que descreve o conteúdo do banco de dados de forma textual ou lógica, enquanto o DER é a representação gráfica desse modelo.

Em resumo:

  • MER: É o conceito (a descrição das entidades, atributos e relacionamentos).
  • DER: É o desenho (a visualização do MER em forma de diagrama).
