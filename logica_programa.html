O que são Linguagens de Programação?

Linguagens de programação são conjuntos de regras, símbolos e comandos usados para escrever programas que orientam o computador a executar tarefas. Elas funcionam como uma “ponte” entre o ser humano e a máquina, permitindo criar softwares, sites, jogos, aplicativos, sistemas embarcados e muito mais. Cada linguagem possui sua própria sintaxe (forma de escrever) e características específicas, sendo escolhida conforme o tipo de aplicação desejada.

  • C++ é rápida e poderosa, ideal para sistemas de alto desempenho, jogos e softwares próximos ao hardware.
  • JavaScript é a linguagem da web, responsável pela interatividade das páginas e também usada no backend.
  • Java é robusta, multiplataforma e muito usada em sistemas grandes, servidores e aplicativos Android.
  • Python é simples e versátil, comum em ciência de dados, IA, automação e desenvolvimento geral.
  • PHP é focada em desenvolvimento web no servidor, muito usado em sites e sistemas dinâmicos como WordPress.

O que é uma linguagem de programação interpretada? e uma linguagem de programação compilada?

Uma linguagem de programação interpretada é aquela cujo código é executado linha por linha por um interpretador. O programa não vira um arquivo executável completo antes de rodar; em vez disso, o interpretador lê, traduz e executa o código em tempo real. Vantagens: fácil de testar e modificar. Exemplos: Python, JavaScript, PHP. Já uma linguagem de programação compilada passa por um compilador, que traduz todo o código-fonte para um arquivo executável antes da execução. Só depois dessa tradução o programa roda diretamente no computador. Vantagens: maior desempenho e velocidade. Exemplos: C, C++, Rust.

O que é HTML e CSS

O que é HTML

HTML (HyperText Markup Language) é a linguagem usada para estruturar o conteúdo de páginas na web. Ela define elementos como títulos, parágrafos, imagens, tabelas, links e botões. O HTML organiza o que aparece na página.

O que é CSS

CSS (Cascading Style Sheets) é a linguagem usada para definir o estilo das páginas web. Com ela é possível controlar cores, tamanhos, fontes, espaçamento, sombras, animações e o layout completo do site. O CSS determina como a página vai aparecer.

Em resumo:

HTML = estrutura e conteúdo. CSS = aparência e design.

O que é uma IDE?

Uma IDE (Integrated Development Environment) é um ambiente de desenvolvimento integrado, ou seja, um programa criado para facilitar a criação de softwares. Ela reúne, em um único lugar, várias ferramentas que ajudam o programador a escrever, organizar, testar e executar códigos. Uma IDE normalmente oferece:

  • Editor de código com realce de sintaxe;
  • Auto-completar (sugestões inteligentes);
  • Depurador (debug) para encontrar erros;
  • Gerenciador de arquivos do projeto;
  • Integração com compiladores ou interpretadores;
  • Execução e testes do programa.


Exemplos de IDEs:


  • VSCode – muito usado, leve e com extensões para várias linguagens.
  • IntelliJ IDEA – poderoso para Java e outras linguagens da JetBrains.
  • PyCharm – focado em Python.
  • Visual Studio – muito usado para C#, C++ e .NET.
  • Eclipse – tradicional para Java e desenvolvimento web.

// Função para converter temperaturas entre Celsius e Fahrenheit
function converterTemp(valor, unidade) {

    // Se a unidade informada for Celsius ("C")
    if (unidade === "C") {
        // Converte de Celsius para Fahrenheit usando a fórmula:
        // F = (C × 9/5) + 32
        return (valor * 9/5) + 32;

    // Se a unidade informada for Fahrenheit ("F")
    } else if (unidade === "F") {
        // Converte de Fahrenheit para Celsius usando:
        // C = (F − 32) × 5/9
        return (valor - 32) * 5/9;

    // Caso a unidade não seja "C" nem "F"
    } else {
        return "Unidade inválida!";
    }
}

// Exemplos de uso da função:

// Converte 20°C → Fahrenheit
console.log(converterTemp(20, "C")); // 68°F

// Converte 68°F → Celsius
console.log(converterTemp(68, "F")); // 20°C

// Função para calcular o IMC de uma pessoa
function calcularIMC(peso, altura) {

    // Fórmula do IMC: peso dividido pela altura ao quadrado
    const imc = peso / (altura * altura);

    return imc; // Retorna o valor calculado
}

// Exemplo de uso da função:
// Peso: 70 kg
// Altura: 1.75 m
// Deve resultar aproximadamente em 22.86
console.log(calcularIMC(70, 1.75)); // 22.86

// Função para gerar uma matriz 3x3 com números aleatórios de 1 a 20
function gerarMatriz() {

    let matriz = []; // Array principal que vai armazenar as 3 linhas

    // Laço externo: controla as 3 linhas da matriz
    for (let i = 0; i < 3; i++) {

        let linha = []; // Cria uma nova linha vazia

        // Laço interno: controla as 3 colunas da matriz
        for (let j = 0; j < 3; j++) {

            // Gera um número aleatório entre 1 e 20
            let numero = Math.floor(Math.random() * 20) + 1;

            linha.push(numero); // Coloca o número dentro da linha
        }

        matriz.push(linha); // Adiciona a linha completa dentro da matriz
    }

    return matriz; // Retorna a matriz final com 3 linhas e 3 colunas
}

// Exibe a matriz gerada no console
console.log(gerarMatriz());

// Função que gera 10 números aleatórios (1 a 220) e soma todos eles
function gerarESomar() {

    let lista = []; // Array para armazenar os números gerados
    let soma = 0;   // Variável onde será acumulada a soma dos números

    // Laço que gera 10 números aleatórios
    for (let i = 0; i < 10; i++) {

        // Gera um número inteiro de 1 a 220
        let num = Math.floor(Math.random() * 220) + 1;

        lista.push(num); // Coloca o número dentro do array
        soma += num;     // Soma o número ao total acumulado
    }

    // Exibe no console a lista completa de números gerados
    console.log("Números gerados:", lista);

    // Exibe no console o valor total da soma
    console.log("Soma total:", soma);
}

// Chamada da função para executar o processo
gerarESomar();

// Função para gerar 'qtde' números aleatórios de 1 a 20

// Função Bubble Sort para ordenar um array
function bubbleSort(arr) {

    // Primeiro laço controla quantas "passadas" serão feitas
    for (let j = 0; j < arr.length - 1; j++) {

        // Segundo laço percorre o array comparando elementos vizinhos
        for (let i = 0; i < arr.length - j - 1; i++) {

        // Verifica se o elemento atual é maior que o próximo
        if (arr[i] > arr[i + 1]) {

        // Guarda o valor atual em uma variável temporária
        let temp = arr[i]

        // Troca os valores de posição
        arr[i] = arr[i + 1]
        arr[i + 1] = temp

        // Logs para mostrar cada troca ocorrendo
        console.log(arr) // mostra o array após a troca
        console.log(`arr[i] = ${arr[i]}`) // novo valor em arr[i]
        console.log(`-----------------------`)
        console.log(`temp (valor trocado) = ${temp}`) // valor que estava antes
        console.log(`-----------------------`)
        console.log(`arr[i+1] = ${arr[i + 1]}`) // novo valor em arr[i+1]
        console.log(`-----------------------`)
        }
    }
}

    return arr // Retorna o array ordenado
}

function buscaLinear(lista, valorProcurado) {
    for (let i = 0; i < lista.length; i++) {
        if (lista[i] === valorProcurado) {
            return i; // retorna a posição onde encontrou
        }
    }
    return -1; // se não encontrar
}

// Exemplo de uso:
let numeros = [4, 8, 15, 16, 23, 42];
let pos = buscaLinear(numeros, 16);

console.log("Posição encontrada:", pos); // saída: 3

A busca linear é o método mais simples para procurar um valor dentro de uma lista ou array. Ela funciona percorrendo os elementos um por um, começando na primeira posição e indo até a última, comparando cada item da lista com o valor procurado. Se encontrar uma correspondência, retorna a posição do elemento; caso percorra toda a lista sem encontrar, retorna –1 indicando que o valor não existe ali.
Esse método é muito fácil de entender e implementar, por isso é bastante usado em listas pequenas ou quando não há garantia de ordenação. Entretanto, em listas grandes ele pode ser lento, pois no pior caso precisa verificar todos os elementos, resultando em uma complexidade O(n).p>
